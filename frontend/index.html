Учет начислений и платежей ЖКУ

Исходящее сальдо месяца рассчитывается автоматически: входящее + начисления − платежи. Входящее сальдо следующего месяца = исходящее текущего. Вручную задается только стартовая строка счета.

1. Оборотная ведомость (все квартиры)

2. Оборотная ведомость по квартире

3. Сводка по категориям должников
